1. WHAT IT IS
-------------
- One Lv 45 hybrid per Triune: 120 skills in total (Appendix A of the guide lists the 120 Triunes).
- Learned at Lv 45 automatically as the player's fourth hybrid (after the Lv 15 and Lv 25 hybrids and the Lv 35 Ultimate).
- It is built from the Triune's three specs. A player's version always has exactly 5 effects:
    3 CORE effects (fixed per Triune) + 2 RIDER effects (one from each of the player's two Minors).
- Only Minors matter at Lv 45. The Lv 50 Major never changes a rider (see 4.5).

2. CORE EFFECTS (3, fixed)
--------------------------
2.1  Exactly one core effect per spec of the Triune, written in that spec's identity and damage type.
     Each is tagged with its spec in the written skill, so the guide's mandatory "[Spec] Aspect" lines
     are satisfied.
2.2  Cores always use the BASE form of each spec. They never change with the player's Minors.
2.3  Each core effect is one grouped effect (8.3): a single idea, no more than two linked numbers.
2.4  The trio must show at least two different archetypes (damage / control / defense / sustain /
     buff-debuff). A Triune skill may not be a pure copy of one archetype.
2.5  No two of the 120 skills may share the same trio of core effects or the same signature mechanic.
2.6  Damage is written as % of the spec's own stat (INT elemental, STR/AGI as the spec's skills use),
     with ONE named damage type per damaging effect (9.7). Single direct hit max 18% of stat.
2.7  No risk/reward mechanics (8.5 forbids them on this tier's defensive and healing skills; none used).

3. STAT BUDGET (why the numbers are fixed)
-------------------------------------------
The Lv 45 hybrid is Advanced tier (8.4). A player can take any two riders, so cores must leave room.
Max core value = Advanced cap minus the worst case of two riders stacking.

4. RIDERS (2 per player, from the Minors)
-----------------------------------------
4.1  There are exactly 20 riders, one per Minor. Table in section 7.
4.2  Evolved-1's Minor supplies Rider A. Evolved-2's Minor supplies Rider B. The unevolved spec

4.3  Riders are SELF-CONTAINED. They act on "the primary target" (the nearest enemy if the core
     has no target) or on you or allies. They never need a damaging core effect to work.
4.4  A rider is one effect and counts as one effect (8.3). Each is sized to the "rider value"
     column in section 3 and never exceeds it.
4.5  Riders follow the Minor's lineage. When a Lv 50 Major replaces a Minor, the rider is unchanged:
     the Major's lineage tells you which Minor it came from.
4.6  The 20 riders live in one shared table (section 7) and are not repeated under each skill. The
     skill entry says "Riders: from your two Minors, see the rider table". Only the two riders that
     match the player's Minors apply.
4.7  A rider can never duplicate a core effect's mechanic exactly. If a core already does the same
     thing (e.g. a root), the core is the one rewritten, not the rider.
