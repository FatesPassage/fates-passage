# Fate's Passage — GitHub Pages Build

Upload the contents of this folder to the repository root. `index.html` must remain at the repository root. GitHub Pages serves this as the site. The game is designed to cache its local files and the Three.js CDN resource after the first successful load so it can run offline afterward.

Core chain: launcher → character creation → Fate's Passage 2 → compass/map, character sheet, House Book/Spell Tome, character sheet/Forge.
